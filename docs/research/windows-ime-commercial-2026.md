# Windows 中文输入法竞品调研：商业与系统内置产品

> 检索日期：**2026-11-06**。范围：当前在 Windows 上可实际安装、且有官方分发证据的中文输入法。所有版本号、安装包时间与更新日志均在检索当日实测抓取。
> 统计口径严格区分：**Windows 端活跃用户**、**全平台/移动端 MAU**、**新增安装**、**商店安装档/下载量**、**系统内置覆盖**。找不到可信的 Windows 输入法份额时明确标注"数据缺口"，不做排名推测。

---

## 1. 结论摘要

1. **在可核验的 PC 数据里，只有搜狗一家第三方输入法进入头部。** QuestMobile 2026 年 9 月 PC 应用活跃用户 TOP10 中，**搜狗输入法是唯一入榜的输入法**（3,529.80 万），其余六款商业输入法均未进入该榜的前十。但"未进前十"不等于"份额小"，"入榜"也不等于"份额可知"——该榜不公布分母，且**不含微软拼音**（系统内置，不作为独立应用统计）。因此本节只能说"搜狗是 PC 端公开数据可见的最大第三方输入法"，**不能推出任何 Windows 份额**。
2. **公开数据里不存在 Windows 输入法市占率。** 中文行业报告（易观、MobTech）的口径全部是"移动端第三方输入法 App"，明确排除预装与 PC。任何把 5.11 亿 / 6.9 亿这类数字当成 Windows 份额的说法都是口径错误。
3. **Windows 端的更新节奏和移动端严重脱节。** 搜狗移动端已到 20.x（2026-01 宣布"全面 AI 化"），**Windows 主力版本仍是 16.x**（2026-10-30 发布 16.10）；百度 Windows 端 2026 年只有 1 次"修复已知问题"；QQ 输入法 2026 年只有 1 个版本。移动端是 AI 战场，桌面端是维护战场。
4. **AI 已经全面进入 Windows 候选窗，但形态高度同质。** 搜狗（AI 帮写 / AI 划词 / 光标助手）、微信（按 `=` 问 AI、语音润色、AI 录音笔）、百度（超会写）、豆包（大模型联想 + 智能整理）、讯飞（星火 + 语音）都在做"候选栏旁边的生成式能力"。**没有一家把生成式 AI 做成默认关闭、可完全离线、且关闭后基础输入不受影响的可验证路径**——豆包的"基础输入模式"最接近，但其生成式能力仍属云端。
5. **"低干扰"已经变成可量化的竞争项。** 搜狗在 2026-02 的 16.2 版加入"商业广告关闭按钮"，2026-08 又全端下线 20 多个广告位并压缩弹窗时长（上证报）。这说明**广告曾经是这一品类最痛的体验负债**，也说明"安静"正在被头部当作卖点收复。
6. **本地优先已有商业先例，但都是"两档模式"。** 微信输入法默认"隐私保护模式"、可开"单机模式"；豆包分"基础输入模式（纯本地）/智能输入模式（云端）"。**没有一家把"默认全本地 + 逐项显式授权云端"做成唯一形态**——这正是 Silk 的定位空间。
7. **对 Silk 的直接结论：不要在功能广度上竞争，要在"默认状态"上竞争。** 默认不联网、默认不学习敏感输入、默认没有商业位、AI 可整体关闭且不影响盲打——这几条在现有商业产品里全部缺席或需要用户手动关。

## 2. 方法与口径

### 2.1 取证方式

- 逐产品访问**官网 / 官方更新日志 / 官方商店页 / 官方隐私政策 / 官方下载 CDN**，记录版本号与安装包 `Last-Modified`。
- 用 winget 官方清单仓库（`microsoft/winget-pkgs`）交叉验证版本号、安装包 URL、架构与发布日期——这是第三方维护但**逐条对应官方 URL 与 SHA256** 的清单，可用于确认"官方确实发布了这个版本"。
- 行业规模只采用数据机构原始页面或其授权转载的主流媒体（QuestMobile、易观、StatCounter）。
- 主观评测、论坛帖、下载站仅作**旁证**，并在文中标注"第三方"。

### 2.2 证据等级

| 等级 | 定义 | 本文用法 |
|---|---|---|
| A | 厂商官网 / 官方更新日志 / 官方隐私政策 / 官方商店 API | 作为事实陈述 |
| B | 官方 CDN 安装包元数据（版本号、时间、大小） | 作为"该版本确实存在且已发布"的证据 |
| C | 数据机构原始报告或主流财经媒体转述 | 作为规模/趋势证据，标注口径 |
| D | 第三方评测、下载站、论坛 | 仅作旁证，明确标注 |

### 2.3 关键口径澄清

| 常见数字 | 真实口径 | 不能用来断言 |
|---|---|---|
| 搜狗"月活 6.9 亿" | 全平台（含移动端），2026-08 上证报引述"接近搜狗人士" | Windows 份额；且与 QuestMobile 的 PC 3,529.80 万不同源、不同期 |
| 搜狗 5.11 亿 / 讯飞 2.42 亿 / 百度 1.44 亿 | 易观：**移动端第三方输入法 App** 月均用户，**排除预装**，2026 年 1–7 月 | PC 或 Windows 数据 |
| 讯飞"新装 1.23 亿第一" | 同上，移动端新增安装 | 存量份额、桌面端热度 |
| Microsoft Store 评分/评分数 | 该商店渠道的样本，非全量用户 | 装机量或满意度总体 |
| winget 清单 | 官方安装包的版本与哈希 | 用户规模 |
| 安装包体积 | 分发物大小 | 运行时内存占用 |

### 2.4 **Windows 市占数据缺口（重要）**

**本次检索未找到任何可信的 Windows 中文输入法市占率或活跃份额数据。** 具体缺口：

1. **QuestMobile PC 榜只列 TOP10 应用**，输入法只出现搜狗一家，没有分母（中国 PC 活跃设备总数未在该榜公布），因此只能做"是否入榜"的判断，**不能算份额**。
2. **微软拼音不作为独立应用被统计。** 它是 Windows 语言功能的一部分，随系统分发，没有任何第三方监测能把它和其他输入法放进同一张份额表。
3. **易观 / MobTech 明确排除 PC 与预装**，其"占有率"（如 MobTech 口径下 2025 年 7 月前三家合计 84.4%）只覆盖移动端第三方 App，且未公开计算定义。参见 [eNet 对易观报告的引述](http://www.enet.com.cn/article/2026/1030/A202610301278809.html)（原文明确"中国**移动端**第三方输入法"）。
4. **厂商不披露分平台数据。** 搜狗、讯飞、百度、微信、豆包均未公开 Windows 端 MAU。
5. 因此本文**不给出任何 Windows 排名**，只给"可核验的 Windows 端证据"（版本、发布节奏、商店信息、PC 端活跃规模）与"不可跨平台外推"的规模数据。

### 2.5 Windows 平台基数（用于理解量级，不是输入法份额）

据 StatCounter 2026 年 8 月数据（经 IT之家转述），中国桌面 Windows 版本分布为 Win11 49.16%、Win10 44.67%、Win7 4.36%、WinXP 1.6%。这意味着**Windows 10 仍有接近一半的中国桌面存量**，任何"只支持 Win11"或"放弃 Win10"的决策都会切掉大量用户。来源：[IT007 转 IT之家](https://www.it007.com/article-332301-1.html)。

## 5. 逐产品分析

### 5.1 搜狗输入法

**定位**：Windows 第三方输入法的在位者，靠词库、整句与"什么都能打"取胜。

**输入方案与核心功能**
- 拼音（全拼/双拼/简拼）、五笔、手写、语音；细胞词库、自定义短语、皮肤。
- 候选条在 2026 年做了两轮重构：16.3b（2026-04-11）新增"按 ↓ 唤出多行候选面板""按 Tab 切换不同服务""精简候选条元素"；16.7（2026-08-03）重做设置中心。
- 词库侧：16.8（2026-08-28）将生僻字字库扩至 **97,908 字**，覆盖 GB 18030-2022 及第 1 号修改单；16.6（2026-06-26）更新打字模型，主打"减少翻页找词"；16.2（2026-02-27）新增"医生/律师定制化模式"。

**AI / 语音 / 云**
- 16.1c（2026-02-11）一次上了 **7 个 AI 帮写服务**（灵感语录、润色、高情商回复、校对、结构化、翻译、写作），并加"AI 光标助手"（在 Word/WPS 中经光标入口唤起续写/润色/翻译）与"窗口跟随"。
- 16.4（2026-04-17）把 AI 划词与窗口跟随扩到更多应用。
- 语音：官方口径"日均语音使用近 20 亿次"（全平台，2026-08 上证报）。桌面端的语音入口存在，但**未公开是否端侧**。
- 云：云输入/联想会上传"部分文本信息 + 当前应用名称"（官方隐私政策明示）；跨设备复制粘贴 16.5 上线（需登录），16.10 改为 **Windows 与安卓免登录即可用**。

**隐私与联网**
- 官方《个人信息保护政策》明示：使用搜索、快捷翻译、**云输入及联想、搜索候选**时，需提供"部分文本信息及当前应用名称"。
- **存在"个性化推送"条款**：基于使用记录、点击记录、IP、浏览行为、下载行为**以及文本信息**做推荐（官方政策 1.2.8）。
- 跨设备复制粘贴会把复制内容上传服务器转发，声明不存储。

**广告 / 打扰**
- **可核验的官方动作**：16.2（2026-02-27）"新增商业广告关闭按钮"——说明商业广告位在桌面端是既成事实，只是现在给了开关。
- 2026-08-21 上证报：搜狗"已启动新一轮全端广告与推广位治理，累计下线 20 多个广告位及推广位，并压缩弹窗停留时间、精简工具入口"，并引述"月活达 6.9 亿"。（[上证报/搜狐转载](https://www.sohu.com/a/1065972534_120988576)）
- 2025-10 曾有"卸载后仍弹广告"的公开争议，官方给出关闭三个选项的路径（第三方媒体报道）。**结论：广告是本产品长期负债，2026 年在系统性收敛，但机制仍在。**

**账号与同步**
- 支持手机号、扫码登录；账号用于跨设备复制粘贴、词库同步、账号绑定管理。

**维护状态**
- 2026 年 1–10 月发布 12 个 Windows 版本（16.1 → 16.10，含 b/c 修订），**是七款里桌面端迭代最密的**。
- 注意口径分裂：**移动端已到 20.x 并宣布"全面 AI 化"（2026-01-27 发布 20.0，官方口径：AI 用户规模破亿、日均语音近 20 亿），Windows 仍是 16.x**。见[中国经济网报道](http://scitech.ce.cn/sy/zx/202601/t20260127_2731874.shtml)、[上证报](https://m.cnstock.com/commonDetail/627475)。宣传材料里的 AI 能力多数以移动端为样本，官方未给桌面/移动能力对照表。

**定价**：Windows 端免费下载、无强制付费墙（官方下载页无价格）。会员/订阅主要出现在移动端（第三方报道 App Store 连续包年 258 元），**桌面端是否收费未取得一手证据**。

**优缺点**
- 优：词库与专业词覆盖最全；候选条交互打磨最细；桌面迭代最快；跨设备免登录已落地。
- 缺：广告机制与个性化推送条款是结构性负担；安装包 220 MB；AI 功能堆叠导致设置项膨胀；移动/桌面版本号割裂，桌面用户拿不到移动端最新 AI。

**对 Silk 的启示**
- 它证明了"词库广度 + 候选条手感"是入场券，也证明了**广告位一旦装进去就很难彻底拆干净**——Silk 的"从不安装商业位"比"提供关闭按钮"更省事、更可信。
- 220 MB 的安装包说明功能堆叠的代价是可见的；Silk 应把"安装包与常驻内存"当成一级指标公开。

### 5.2 微软拼音（Microsoft Pinyin）

**定位**：Windows 系统内置的中文 IME，Silk 最直接的"零成本基线"。

**输入方案与核心功能**（一手：Microsoft Learn + 官方支持页）
- 全拼、双拼、模糊拼音、超简拼；整句转换。
- **U 模式**：按笔画/部件拆字输入，或输入符号。
- **V 模式**：中文数字、日期、时间、公式，以及 Unicode / GB-18030 码位输入（可直接把 `U+7389` 转成"玉"）。
- 人名输入（`;` + `R`）、域词典（可按学科开关）、用户自定义短语（支持从文本文件批量导入）、Emoji 与符号面板、IME 工具栏。
- 五笔 IME 作为独立键盘布局提供（需在语言选项里手动添加）。

**AI / 语音 / 云**
- **没有生成式 AI，没有语音输入。** 这是它与全部商业竞品的最大差异。
- 唯一的云端能力是 **Bing 文本建议**：候选窗里带云图标的联想，默认需用户主动开启（Win11 为 "Try text suggestions from Bing"，Win10 为 "Cloud service"）。**基础输入完全本地完成。**

**隐私与联网**
- 基础输入不联网；联网仅限用户显式开启的 Bing 建议。
- 无账号体系、无遥测式"体验改进计划"开关暴露在输入法设置里（系统级诊断另属 Windows 隐私设置）。

**广告 / 打扰**：无。系统组件不存在商业位。

**账号与同步**：无。词库自学习存本地，不跨设备同步（跨设备能力由 Windows 剪贴板等系统功能另提供）。

**维护状态**：随 Windows 更新。官方支持页明确 **Windows 10 已于 2025-10-14 结束支持**，之后不再有免费功能/安全更新——这对仍占中国桌面约 44.67% 的 Win10 存量（StatCounter 2026-08）是实质影响。

**定价**：随系统，免费。

**优缺点**
- 优：零安装、零广告、零账号、默认本地；U/V 模式与域词典是被低估的能力；对系统集成（UILess、搜索框、锁屏）天然正确。
- 缺：长句与专业词准确率弱于商业头部；无语音；无跨设备；自学习能力弱、无可视化词库管理；Win10 停止支持后不再演进。

**对 Silk 的启示**
- **这是 Silk 必须打平的基线，而不是可以忽略的对手。** 用户切换成本极低，Silk 必须在前 10 分钟就证明"长句更准、候选更稳"，否则没有理由离开。
- U/V 模式、域词典、短语批量导入这类"低频但高价值"的能力，微软已经免费给了——Silk 要么做到同等，要么明确不做，不能半吊子。
- **"默认不联网 + 无账号"不是差异化，是及格线。** Silk 的差异化必须在"更好用"上，而不是"更干净"上——因为干净的免费替代品已经预装好了。

### 5.3 微信输入法

**定位**：微信团队出品，主打"简洁、克制、隐私"，是近三年唯一在 Windows 端持续高频迭代的新入局者。

**输入方案与核心功能**
- 拼音（全拼/双拼/简拼）、五笔、手写、符号/表情面板；`v` 键唤起功能面板（V 功能、剪贴板、常用语，仅拼音）；繁体输入；日期时间多格式输入；候选词右键"固定到首位/删除"。
- 智能拼写（易错音、符号配对）、模糊拼音、中英/数字间自动加空格。

**AI / 语音 / 云**（全部有官方更新日志佐证）
- 1.2.0（2024-06）起：输入内容后按 `=` 直接获取 AI 回答；后续支持"优化表达""边写边译"。
- 1.3.0：问 AI 支持 **DeepSeek-R1 / Hunyuan-T1** 深度回答。
- **2.1.0（2026-06-08）语音大升级**：长按 `Ctrl+Win` 说话，自动去口水词、智能加标点分段、长内容自动归纳分点、理顺语序、去重复。
- 2.1.3（2026-08-31）语音支持实时转写到输入框；3.0.0（2026-10-15）新增 **AI 录音笔**（生成可分享内容）。
- 跨端：2.0.0（2026-05-09）"隔空传送"，支持跨设备及面对面秒传图片文件。

**隐私与联网**（一手：官方隐私政策，2026-09-21 生效）
- **默认"隐私保护模式"**：输入内容不上传，仅本地存储；本地用字符串匹配触发表情/纠错等。
- **"拼写Plus"为可选扩展**：开启后才上传"部分输入内容 + 城市归属地"做实时处理；语音转文字、边写边译、跨设备同步均需开启并上传对应内容，声明**不存储**。
- **"单机模式"**（1.2.3，2024-08）：提前缓存词库到本地并禁用联网，代价是语音转文字与跨设备功能不可用。
- 无需注册登录即可使用基础功能。

**广告 / 打扰**：官网与 37 条 Windows 更新日志中**未出现任何广告位、推广位或会员入口**；产品自我定位为"简洁好用打字快"。第三方对比文章普遍描述为"无广告"。（此为"官方材料中不存在"的观察 + 第三方旁证，非官方承诺。）

**账号与同步**：可选登录；跨设备同步词库与常用语；不登录也能用。

**维护状态**：2026 年官方日志记录 **7 个 Windows 版本**（2.0.0 → 3.0.0），另有 1 次未入日志的安装包更新（3.0.2.29，2026-11-03）；功能密度高（语音、隔空传送、AI 录音笔）。**是桌面端产品思维最活跃的一家。**

**定价**：免费，官网无付费入口。

**优缺点**
- 优：默认本地 + 可选云端的两档设计最接近"可验证的隐私边界"；语音链路（长按唤起 → 去口水词 → 结构化）体验完整；迭代快；ARM64 原生支持。
- 缺：AI 能力全部依赖联网与腾讯云；"拼写Plus"一旦开启，输入内容与城市归属地会上传（虽声明不存储）；功能仍围绕微信生态（表情推荐、隔空传送与微信/企微强耦合）；跨设备功能需登录。

**对 Silk 的启示**
- **"默认本地、可选云端、单机模式"这个三段式是当前最成熟的产品答案**，Silk 应当直接对齐并把默认值再收紧一档（连 Bing 式建议都默认关）。
- 它的语音路径（说完 → 去口水词 → 加标点 → 分点）是"AI 增强输入"最不打扰的形态：**AI 只处理用户已经说出的内容，不替用户思考**。这比"候选栏里塞一个全能助手"更值得抄。
- 它证明"每月一版"的桌面迭代是可以做到的——Silk 的维护节奏应以此为下限参考。

### 5.4 QQ 输入法

**定位**：腾讯老牌轻量拼音，现由搜狗侧运营（下载域名、CDN 均为搜狗体系）。

**输入方案与核心功能**
- 全拼/简拼/双拼、五笔、笔画、手写、整句输入、智能纠错、繁简转换、细胞词库、皮肤。
- 有独立的"个人中心"：QQ 账号登录后可看**输入等级、活跃天数、好友排名、电脑/手机打字统计**——这是七款里唯一的"游戏化"设计。

**AI / 语音 / 云**：**无生成式 AI 能力，无语音输入宣传。** 云能力限于词库同步与账号数据。

**隐私与联网**：官网无独立隐私政策页（帮助中心只有账号/等级/统计说明）；从产品形态看数据用途主要是账号与词库同步。**隐私条款细节未取得一手文档，属证据缺口。**

**广告 / 打扰**：官网自我描述为"更快、更准、**更绿色**的输入法""占用资源小"；第三方下载站普遍称"广告比其他输入法少得多"。**无一手证据证明当前无广告位**，标注为旁证。

**账号与同步**：QQ 账号登录，词库与打字统计跨端同步。

**维护状态**：**2026 年只有 1 个版本**（6.7.6500.400，2026-06-24）。官网首页版权标注仍为 "© 2020"，页面结构停留在旧时代。winget 清单同期更新，说明发布是真实的，但**产品处于维护模式而非演进模式**。

**定价**：免费。

**优缺点**
- 优：安装包仅约 60 MB（七款最小）；资源占用低；无强制 AI 干扰；QQ 生态账号打通。
- 缺：功能长期停滞（无 AI、无语音创新）；官网陈旧、信息架构老化；隐私文档缺失；生态位被搜狗自家产品挤压，战略优先级低。

**对 Silk 的启示**
- **"轻"是有市场的**：60 MB、低占用、无 AI 噪音，仍然有稳定用户。Silk 的"极致轻量"定位不是空想，QQ 输入法是它的现实参照（也是它的失败参照——轻量不能等于停滞）。
- **停滞的产品会被慢慢遗忘**：一年一版、官网 © 2020，用户感知到的不是"稳定"而是"没人管"。Silk 需要稳定的发布节奏来证明"还在"。
- **游戏化（等级、打字统计）是低成本留存手段**，但对"安静"定位是双刃剑——Silk 若要借鉴，应做成纯本地、可关闭的统计，而不是社交排名。

### 5.5 百度输入法

**定位**：移动端第三，桌面端"有产品但低投入"。

**输入方案与核心功能**
- 拼音、五笔、手写、中英混输、方言语音；皮肤与个性化；生僻字方案（[官方专题页](https://srf.baidu.com/site/rarelyusedcharacters/index.html)称覆盖 89,000+ 汉字与符号，符合 GB 18030-2022）。

**隐私与联网**：官网未在下载页暴露隐私政策入口；AI 与云能力必然联网。**具体条款未取得一手文档，属证据缺口。**

**广告 / 打扰**：第三方实测称"有会员推荐，输入框推广偶尔也有"。**无一手证据**，标注为旁证。

**维护状态**：官方更新日志显示 **2026 年仅 1 次更新（6.1.13.13，2026-07-01，"修复已知问题"）**；2025 年 2 次，均为修复或"基础输入体验优化"。**桌面端处于低维护状态。**

**优缺点**
- 优：生僻字与词库底子厚；"超会写"在文档场景有明确用例；桌面端与移动端账号打通。
- 缺：桌面端 2025 年后几乎停更；AI 能力落后于搜狗/微信/豆包的当前版本；收费体系复杂且口碑受损（第三方投诉报道）；隐私文档不透明。

**对 Silk 的启示**
- **"曾经做过 AI，然后停更"是最差的组合**：用户记得那些入口，但它们不再变好。Silk 若上 AI，必须承诺维护节奏，宁可不做也不要留半死的入口。
- **收费墙 + 广告 + AI 三者叠加会摧毁信任**。Silk 的开源免费模型在这里是结构性优势，应明确写进产品承诺。

### 5.6 讯飞输入法

**定位**：语音能力最强的中文输入法品牌，桌面端是"语音外设"而非主力输入法。

**输入方案与核心功能**
- 拼音（全拼/简拼/双拼）、五笔（86/98/新世纪）、手写、笔画；方言词库；跨屏输入、拍照输入（移动端为主）。
- 官方（移动端口径）：通用语音识别率 98%、支持粤语/四川话等 **26 种方言**、语音输入 1 分钟 400 字。

**AI / 语音 / 云**
- 星火大模型 + 端云协同；移动端有"AI 键"、智能体平台。
- 桌面端（3.0.1750）以**语音输入**为核心卖点，第三方资料称支持离线语音模型、安静/嘈杂双模式、长语音自动断句加标点。
- **桌面端无独立 AI 产品页**，官网"Windows 版"按钮直接触发下载，没有功能说明页——这本身说明桌面端不是重点。

**隐私与联网**：默认云同步（第三方资料）；官网未提供输入法专属隐私政策入口（集团隐私页存在但未与产品绑定展示）。**属证据缺口。**

**广告 / 打扰**：第三方评测普遍称"无广告无弹窗"（等级 D）；也有实测称"弹窗有，还会推荐会员"。**两种说法冲突且均无一手证据，本文不作判断。**

**账号与同步**：讯飞账号，多端词库/设置同步。

**维护状态**：**桌面端 3.0.1750 发布于 2026-03-06，此后至检索日无新版**；官网页面标注的版本号（V3.0.1732）甚至落后于实际安装包。移动端仍在高频迭代。

**定价**：免费 + 增值（第三方称按"火力值"计费，2024 年报道）。**桌面端收费口径未取得一手证据。**

**优缺点**
- 优：语音识别与方言覆盖是行业最强项；离线语音对弱网/隐私场景有价值；五笔方案齐全。
- 缺：桌面端投入明显不足（8 个月无更新、无产品页）；界面与设置偏移动端移植；隐私文档不透明；语音之外的基础输入手感弱于搜狗/微信。

**对 Silk 的启示**
- **语音是"高价值但高成本"的能力**：讯飞用整家公司押注语音才做到这个水平，Silk 若要做，应限定在"可选、离线、短句"的最小范围，不要承诺通用听写。
- **桌面端不是重点就会被用户感知**（无产品页、版本号滞后、8 个月不更新）。Silk 既然 Windows 优先，就必须把桌面端当成唯一主场来投入。
- **隐私文档不透明会直接抵消"无广告"的好感**。Silk 应把隐私边界做成可读的产品文档，而不是法律附件。

### 5.7 豆包输入法

**定位**：字节跳动 2025-11 入局，**语音优先 + 大模型**，2026-09-08 补齐 Windows（首发 V0.9.0，适配 Win10/Win11 64 位），是唯一"新入局且 Windows 原生设计"的样本。首发信息见 [站长之家](https://www.chinaz.com/2026/0909/1775971.shtml)、[网易科技](https://www.163.com/dy/article/L6BBOS300511CPVM.html)（等级 C，厂商未单发公告页）。

**输入方案与核心功能**
- 拼音（全拼/双拼）、九键/26 键（移动端）、手写；**极致简拼**；长句补全、随打随纠、智能联想。
- 官方定位语："高效输入，享受输出"；"越用越准的键盘输入""大篇幅文字输入可优化整理"。

**AI / 语音 / 云**
- **豆包同款语音识别（Seed-ASR）**：方言、专业术语、中英混输；嘈杂环境与轻声输入；**支持下载离线语音资源包，本地转写**。
- **大模型打字**：智能联想、长句补全、随打随纠。
- **智能文字整理**：把零散口语整理成连贯书面表达（补全语意、梳理重点）。
- **超级互传**：跨端复制粘贴。
- Windows 端当前版本 1.0.0.23（2026-11-02），四个多月从 0.9.0 走到 1.0。

**隐私与联网**（一手：官方隐私政策，2026-08-18 生效）
- **基础输入模式**：键盘输入仅本地字符串分析，**输入内容不上传**；离线语音包在**本地**完成转写；个人词库与常用语仅存本地。
- **智能输入模式**（可选）：云端获取输入/上屏的部分文本与应用场景信息做预测与联想，声明不存储；语音转文字会上传语音（不存储）；翻译会上传待译文本（不存储）。
- 通讯录导入**在本地完成**，仅提取人名。
- **体验改进计划**：需用户主动打开开关，才会收集输入串、语音转文字信息、音频等。
- 登录豆包账号才做多端词库同步。
- **注意**：政策 3.3 条声明可能通过短信/电话向用户提供的手机号发送"商业性信息"（可退订）——这与"无广告"的产品印象是两件事，但对"零打扰"承诺是一个需要读者知晓的边界。

**广告 / 打扰**：官网页面无广告位、无会员入口；第三方评测一致称"无广告、不弹窗、无会员弹窗"。**官方材料中不存在广告位**（观察），第三方旁证一致。

**账号与同步**：豆包账号（可选），登录后同步个人词库；不登录亦可用。

**维护状态**：2026-09-08 首发 Windows 0.9.0 → 2026-11-02 已到 1.0.0.23（winget 清单另记录 0.9.2.7、0.9.3.20），迭代最快的新产品。移动端 2025-11 起，官网现列 Windows / macOS / iOS / Android / HarmonyOS NEXT 五端。

**定价**：免费，无付费入口。

**优缺点**
- 优：语音体验（离线包 + 口语整理）是当前最强的一档；隐私分为"基础/智能"两档且默认基础本地；无广告；Windows 端从零设计，不受移动端包袱。
- 缺：安装包 318 MB（七款最大，离线语音模型是主因）；**仅 x64，无 ARM64**；基础输入（双拼方案、专业词库、自定义短语）仍在补齐期；跨端同步要登录豆包账号；产品仅一年，长期维护承诺未知。

**对 Silk 的启示**
- **"默认本地 + 可选云端"已被豆包用产品语言实现**，且它证明了**离线语音包可以作为一个显式的、可下载可删除的资产**——这正是 Silk 应采用的模型分发形态（而不是把模型塞进安装包）。
- **318 MB 是"AI 优先"的真实代价**。Silk 若坚持轻量，就不能把语音模型打进主安装包，必须做成分离的可选组件。
- **它把"智能文字整理"做成了独立功能而非隐式改写**：用户明确触发，才处理。Silk 的 AI 应遵循同一原则——**显式触发、结果可拒绝、不改写用户已上屏的内容**。

## 7. 对 Silk IME 的具体启示

> 以下为基于上述证据的判断，不是市场事实。

### 7.1 定位：不要和搜狗比词库，要和微软拼音比"值得切换"

- 微软拼音已经免费、无广告、无账号、默认本地，并且预装。**"干净"不是差异化，"更好用"才是。**
- Silk 必须在**首次使用的 10 分钟内**证明三件事：长句准确率更高、候选排序更符合直觉、宿主兼容（Electron/游戏/高 DPI/远程桌面）不出错。这三条决定了用户会不会留下。
- 反过来，**不要试图在功能数量上对齐搜狗**。220 MB / 318 MB 的安装包已经证明这条路线的代价。

### 7.2 隐私：把"两档模式"升级为"默认零联网 + 逐项授权"

- 微信的"隐私保护模式 / 单机模式"、豆包的"基础 / 智能模式"是当前最成熟的产品答案。**Silk 应当直接采用这个结构，但把默认值再收紧一档**：
  - 装机后**不存在任何网络请求**（包括更新检查需显式开启，或走系统包管理器）。
  - 云端能力（语音、翻译、AI、词库、跨设备）**逐项独立授权**，不做"一键开启全部"。
  - 提供一个**可验证的开关**：设置页直接显示"本次会话网络请求数：0"，比十页隐私政策更有说服力。
- 搜狗的"个性化推送基于文本信息"条款是反面教材：**一旦把输入内容用于推荐，隐私承诺就破产了**。Silk 应在架构上保证输入内容无法到达任何推荐管道。

### 7.3 AI：只做三种形态，且必须显式触发

行业已经收敛出三种不打扰的 AI 形态，Silk 应按此裁剪：

1. **候选增强（本地）**：整句纠错、上下文排序。这是唯一应该"默认开启"的 AI，且必须能一键关闭并立即回到纯词典路径。
2. **语音后处理（可选、离线优先）**：参考微信"去口水词 → 加标点 → 分点"与豆包"离线语音包"。**模型必须是独立可下载、可删除的组件**，不能塞进主安装包（豆包 318 MB 是前车之鉴）。
3. **显式生成（可选、默认关）**：润色/翻译/续写，用户明确选中文本并触发才执行，**绝不隐式改写已上屏内容**——这是七款产品共同遵守的边界。

**不要做**：候选栏常驻 AI 入口、输入法内置问答助手、AI 宠物/陪伴、AI 搜索。搜狗和百度都做了，代价是设置项膨胀与隐私条款复杂化。

### 7.4 低干扰：把"没有商业位"写进产品契约

- 搜狗 2026 年的两步（加"商业广告关闭按钮" → 下线 20 多个广告位）说明：**广告位一旦装进去，拆除成本极高，且用户不会忘记**。
- Silk 的最优策略不是"提供关闭按钮"，而是**架构上不存在广告 SDK**。这可以直接写进 README 与发布说明，成为可审计的承诺（开源项目可以用"无网络权限 / 无第三方 SDK"这类技术事实来证明，而不是靠声明）。
- 同理适用于：不做开屏、不做节日运营弹窗、不做"装扮商城"、不做会员入口。

### 7.5 维护：桌面端必须是主场，节奏要可预期

- 讯飞 8 个月无新版、官网版本号还写着 3.0.1732；QQ 一年一版、官网 © 2020；百度一年一次"修复已知问题"。**用户能感知到"没人管"。**
- 参照微信（官方日志 7 版/年）与搜狗（12 版/年），Silk 应给出**可预期的发布节奏**（例如每月一个稳定版 + 明确的 LTS 分支），并在 release notes 里写清"本次改了什么、没改什么"。
- **长期支持承诺要覆盖 Win10**：中国桌面仍有约 44.67% 是 Win10（StatCounter 2026-08），而微软已于 2025-10-14 停止其支持。这意味着**微软拼音在 Win10 上不再演进**——这恰恰是 Silk 的窗口期。

### 7.6 轻量：把"安装包与常驻内存"做成公开指标

| 产品 | 安装包 |
|---|---|
| QQ 输入法 | ~60 MB |
| 讯飞 | ~112 MB |
| 百度 | ~141 MB |
| 微信 | ~218 MB |
| 搜狗 | ~220 MB |
| 豆包 | ~318 MB |

- QQ 输入法证明 60 MB 可以做出可用的拼音输入法；豆包证明"语音优先"要付 5 倍的体积代价。
- Silk 应把**主安装包目标（如 < 30 MB）+ 可选组件（语音模型单独下载）** 写成设计要求，并在 CI 里对二进制体积做回归检查。

### 7.7 不要做的清单（基于竞品踩过的坑）

| 不做 | 依据 |
|---|---|
| 候选栏商业推广位 | 搜狗 2026 年花两次动作才收敛，且 2025 年"卸载后仍弹广告"直接损害品牌 |
| 基于输入内容的个性化推荐 | 搜狗隐私政策 1.2.8 明示会基于文本信息推送，是隐私承诺的结构性漏洞 |
| 把 AI 模型打进主安装包 | 豆包 318 MB，且仅 x64；体积直接限制了分发与更新成本 |
| 隐式改写用户已上屏文本 | 七款产品无一采用，用户对"输入法改我的字"容忍度极低 |
| 账号强绑 | 微信/豆包/微软拼音均可在不登录状态下完成核心输入；搜狗跨设备也已改为免登录 |
| 只在移动端更新、桌面端挂机 | 讯飞/百度/QQ 的桌面端停滞已被用户与媒体反复指出 |

### 7.8 可以直接借鉴的三个具体设计

1. **微软拼音的 U/V 模式**：低频但高价值（拆字输入、码位输入、日期/公式）。Silk 应实现等价能力，这是"专业用户"的粘性来源。
2. **微信的"长按 Ctrl+Win 说话 → 自动结构化"**：AI 只处理用户已说出的内容，是最不打扰的增强形态。
3. **豆包的"离线语音包"作为可下载资产**：解决了"轻量"与"AI"的根本矛盾，Silk 应把它做成一等公民（可下载、可校验、可删除、可离线校验版本）。
