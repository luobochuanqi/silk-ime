## 决策速览

| ADR | 决策 | 一句话理由 |
| --- | --- | --- |
| 1 | 薄 TSF DLL + 每用户单实例 host | 进程内代码面最小，行业收敛形态 |
| 2 | shim 用 Rust + windows-rs | 进入所有进程的代码要内存安全；绑定完整、有先例 |
| 3 | 渲染实现一份（`silkui`），部署两路 | 进程外被系统 UI 遮挡、进程内有崩溃史，双路互为兜底 |
| 4 | 命名管道 + 长度前缀 JSON 封套 | 零代码生成依赖，预算内；留二进制升级路径 |
| 5 | host 懒启动、空闲自退出 | 零后台驻留，符合"安静" |
| 6 | 注册走 shim 导出函数 | 注册表布局与 COM 调用只有一处定义 |
| 7 | 词库只读资产 + 纯文本用户数据 | 可迁移、可手改是产品前提 |
| 8 | 任何故障不丢按键 | fail-open 降级，最差退化为英文键盘 |

## 关键预算

| 指标 | 预算 |
| --- | --- |
| 按键到候选显示（端到端） | p95 ≤ 30 ms |
| 引擎 `Handle`（首屏 10 候选） | p95 ≤ 5 ms |
| shim 等待 host 硬超时 | 30 ms，超时按键直通 |
| 候选窗单帧渲染 | ≤ 8 ms |
| 冷启动到首个候选 | ≤ 150 ms |

## 术语

| 术语 | 含义 |
| --- | --- |
| TIP | Text Input Processor，TSF 框架的输入法实现形态 |
| TSF | Text Services Framework，Windows 现代文本服务框架 |
| shim / `silk-tsftip.dll` | 进程内 TSF 适配层 |
| host / `silkhost.exe` | 每用户单实例的引擎宿主进程 |
| `silkui` | 候选窗渲染库（独立 DLL，C ABI），host 常驻加载、shim 兜底按需加载 |
| `host_render` | 候选窗在宿主进程内就地渲染的兜底通道 |
| preedit | 组字串（尚未上屏的输入缓冲显示） |
| 基座 | 本设计的范围：可靠输入的最小底座，不含产品层功能 |
